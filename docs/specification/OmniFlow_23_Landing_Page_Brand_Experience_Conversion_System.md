# OMNIFLOW V1 --- CAHIER DES CHARGES CLAUDE CODE

# PARTIE 23 --- LANDING PAGE, BRAND EXPERIENCE & CONVERSION SYSTEM

## 23.1 --- Objectif

La landing page OmniFlow doit être entièrement reconstruite.

Ne pas conserver l'ancienne landing page comme base visuelle ou
structurelle.

Le site existant doit être considéré comme une ancienne version.

Pour cette refonte :

# REBUILD THE LANDING PAGE FROM SCRATCH.

La landing page doit présenter OmniFlow comme un produit :

-   premium
-   technologique
-   IA
-   fluide
-   moderne
-   crédible
-   orienté performance et revenu

Elle ne doit pas ressembler à un template SaaS générique.

## 23.2 --- Positionnement visuel

Le nom :

# OMNIFLOW

doit guider l'identité.

Le design doit mélanger :

### PREMIUM

-   sobriété
-   espace
-   hiérarchie forte
-   détails raffinés
-   typographie premium

### AI / TECHNOLOGY

-   profondeur
-   lumière
-   interactions
-   mouvement
-   visualisation de données
-   interfaces intelligentes

### FLOW

-   transitions fluides
-   éléments continus
-   mouvements horizontaux
-   connexions
-   animations organiques
-   navigation naturelle

## 23.3 --- Direction générale

Éviter :

-   landing page statique
-   blocs rectangulaires génériques
-   gradients IA clichés partout
-   trop de texte
-   animations décoratives sans fonction
-   design crypto
-   surcharge néon
-   effet gaming

Chercher :

# CONTROLLED FUTURISM.

Le produit doit sembler avancé sans devenir kitsch.

## 23.4 --- Dark-first

Direction recommandée :

-   interface sombre
-   contrastes premium
-   surfaces légèrement différenciées
-   effets lumineux subtils
-   accents cohérents avec le logo OmniFlow

Les couleurs exactes doivent être définies à partir de l'identité
visuelle retenue.

## 23.5 --- Logo

Utiliser les nouveaux assets OmniFlow validés :

-   wordmark OmniFlow
-   symbole/logo séparé

Ne pas ajouter de baseline directement dans le logo.

Le logo doit pouvoir fonctionner :

-   navbar
-   favicon/app icon
-   login
-   dashboard
-   loading state
-   social assets

## 23.6 --- Motion System

Créer un système d'animation cohérent.

Le mouvement doit communiquer :

-   intelligence
-   vitesse
-   flow
-   continuité

Animations possibles :

-   hover transitions
-   magnetic buttons légers
-   card tilt très subtil
-   parallax
-   scroll reveal
-   animated connections
-   flowing lines
-   number transitions
-   dashboard data motion

Ne pas tout animer simultanément.

## 23.7 --- Performance

La landing doit rester rapide.

Priorité :

1.  conversion
2.  lisibilité
3.  performance
4.  animation

Pas l'inverse.

Utiliser :

-   lazy loading
-   optimized assets
-   GPU-friendly transforms
-   reduced-motion support

Éviter une énorme scène 3D qui détruit les Core Web Vitals.

## 23.66 --- Critère de réussite

La Landing Page est réussie lorsque :

-   elle semble premium dès les premières secondes
-   OmniFlow possède une identité visuelle reconnaissable
-   les animations renforcent le concept de Flow
-   la proposition de valeur est comprise rapidement
-   le visiteur comprend que l'IA fait plus que répondre
-   la mémoire et l'intelligence commerciale sont visibles
-   la différence Copilot / Full AI est claire
-   le modèle 2,5 % est transparent
-   le ROI est démontré simplement
-   Full AI paraît être l'offre premium logique
-   la page reste rapide
-   la version mobile reste excellente
-   aucun élément majeur de l'ancienne landing n'est conservé par défaut
